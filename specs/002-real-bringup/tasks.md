## Notes

- **Test-first is non-negotiable** (Constitution VI): do not start an implementation task whose paired red test is not committed and failing/skipping as expected.
- **Opt-in suite discipline** (SC-003): every real-Ollama test carries `[Trait("RequiresOllama","true")]` + probe skip; a machine without `http://localhost:11434` must see SKIP, never FAIL.
- **Offline invariant** (Constitution IV): no task may introduce any non-configured egress; `ollama pull` only ever manual, pre-WAN-off (quickstart step 1).
- **FR-005 scope fence**: ONNX/LLamaSharp packages stay installed behind `Ingest:Embedder` non-default flag; tokenizer correctness remains in `todo.md` — explicitly NOT fixed by any task here.
- **Single-tenant** (Constitution I): no `company_id`/tenant parameter introduced by the guard, auth/me, or client wiring.
- **ClientSession is memory-only** (data-model.md): do not persist role/keys to SQLite or LanceDB.
- Dev config fix in T009 is load-bearing: current `appsettings.json` pairs `VectorSize:384` with `nomic-embed-text` (768d) — the guard from T008 would (correctly) refuse to ingest; align config first.
- Mobile on-device (iOS/Android) is a non-goal for this feature (Q1) — TFMs must keep building, no acceptance tasks target phones.
- Commit after each task or logical red→green pair; stop at any checkpoint to validate the story independently per spec Independent Tests.
