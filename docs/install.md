# Installing the RAGGit App (for employees)

RAGGit is your company's private document library. IT has already set up
everything — installing the app takes about two minutes.

## What you need

- A company Windows PC (Windows 10 or 11).
- The install link from IT (it looks like a normal web address).
- Your RAGGit username and password (ask your manager or IT if you don't
  have one yet).

## Install

1. Open the install link IT sent you in your browser.
2. Double-click the downloaded **RAGGit** file.
3. If Windows asks "Do you want to install this app?", click **Install**.
   (If Windows warns about an untrusted app, stop and contact IT — do not
   bypass the warning.)
4. Find **RAGGit** in the Start menu and open it.

## Sign in and use it

1. Type your username and password and press **Sign in**.
2. You land in the **Document Library**. Use **Ask** to ask questions in
   everyday language — every answer shows the documents it came from.
3. The app updates itself automatically; you never need to reinstall it.

## If something goes wrong

- **"Can't reach the AI workstation"**: you need the office network or VPN.
  Connect and try again.
- **Wrong username or locked out**: contact IT or your admin — they can
  reset your password.
- **Anything else**: note what you clicked and what the app said, and send
  it to IT.
